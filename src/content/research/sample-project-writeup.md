This is a sample project entry — delete or overwrite it.

The site deliberately has no Projects tab: GitHub is the canonical list, and
each repository's README tells that story. This collection is for the cases
where a repository isn't the right container — a longer analysis, a comparison
across several projects, or writing you want to point someone at directly.

## Notes

Set `type: project` for these, `type: informal` for exploratory work that isn't
tied to a repository at all, and `type: academic` for coursework and papers.
